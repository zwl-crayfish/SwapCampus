## 2 总体设计

### 2.1 设计目标与原则

| 原则 | 说明 |
|------|------|
| **前后端分离** | 前端 Vue 3 + 后端 Spring Boot，通过 REST API 通信，独立开发部署 |
| **无状态服务** | JWT 鉴权，服务端不存储会话，易于水平扩展 |
| **分层架构** | Controller → Service → Repository 三层分离，职责清晰 |
| **DDD 轻量实践** | 按业务域划分包结构（user/goods/order/message），避免"上帝类" |
| **约定优于配置** | Spring Boot 自动配置 + MyBatis-Plus 代码生成减少样板代码 |
| **最小权限** | 公开接口与认证接口分离，管理员接口独立鉴权 |
| **可演进性** | 预留 ≥3 个扩展点（推荐系统、邮件柜接入、AI 定价） |

### 2.3 技术选型与理由

| 层级 | 选型 | 理由 |
|------|------|------|
| **后端框架** | Spring Boot 3.2 | 课程推荐；生态成熟；自动配置减少样板代码 |
| **ORM** | MyBatis-Plus 3.5 | 相比 JPA 更灵活；代码生成器减少 CRUD 开发量；Lambda 查询安全 |
| **鉴权** | Spring Security + JWT (jjwt 0.12) | 无状态设计便于扩展；课程明确要求 JWT |
| **数据库** | MySQL 8.0 | 课程推荐；事务支持完善；全文索引支持中文搜索 |
| **缓存** | Redis 7 | Spring Boot 默认集成；适用于 Token 黑名单/热点数据 |
| **对象存储** | MinIO | 开源、S3 兼容 API、可本地部署、课程推荐 |
| **即时通讯** | WebSocket (STOMP) | 课程要求 ≤200ms 延迟；Spring 原生支持 |
| **前端框架** | Vue 3 + Element Plus | 课程推荐；Composition API；中文社区活跃 |
| **构建工具** | Vite 5 | 比 Webpack 更快；Vue 3 官方推荐 |
| **容器化** | Docker Compose | 课程要求一键部署；环境一致性 |

## 7 架构决策记录 ADR

### 7.1 ADR-001: 单体架构 vs 微服务

| 属性 | 内容 |
|------|------|
| **Status** | 已采纳 |
| **Context** | 系统功能模块 6 个，团队 3-4 人，开发周期 4 天 |
| **Decision** | 采用 Spring Boot 单体应用，按包分层 |
| **Consequences** | 优点：开发快、调试方便、部署简单（一个 JAR）；缺点：未来扩展为微服务需重构 |
| **Alternatives** | 微服务架构：过度设计，运维复杂，不适合 4 天开发周期 |

### 7.2 ADR-002: MySQL 8 选型

| 属性 | 内容 |
|------|------|
| **Status** | 已采纳 |
| **Context** | 需要持久化存储，支持全文搜索、事务、外键约束 |
| **Decision** | 选择 MySQL 8.0，使用 InnoDB 引擎 |
| **Consequences** | 事务可靠、全文索引支持中文搜索；扩展性受限但课程项目不需要 |
| **Alternatives** | PostgreSQL 16：功能更强但课程要求 MySQL；MongoDB：无事务保证 |

### 7.3 ADR-003: JWT 鉴权方案

| 属性 | 内容 |
|------|------|
| **Status** | 已采纳 |
| **Context** | 需要鉴权方案，系统为前后端分离的 Web 应用 |
| **Decision** | 采用 JWT (jjwt 0.12)，24 小时过期，密钥通过环境变量注入 |
| **Consequences** | 无状态、便于水平扩展；Token 无法主动失效（可通过 Redis 黑名单解决） |
| **Alternatives** | Session 方案：需要服务端存储，违背无状态原则；OAuth2：复杂度过高 |

### 7.4 ADR-004: WebSocket STOMP vs 原生 WebSocket

| 属性 | 内容 |
|------|------|
| **Status** | 已采纳 |
| **Context** | 即时通讯模块需要实时双向通信 |
| **Decision** | 采用 STOMP over WebSocket，Spring 原生支持 |
| **Consequences** | 开发简单、自带目标订阅路由；依赖 SockJS 降级兼容 |
| **Alternatives** | 原生 WebSocket：灵活但需要自己实现消息路由；HTTP 轮询：延迟高 |

## 9 错误处理与日志策略

| 类别 | 策略 |
|------|------|
| **业务异常** | RuntimeException → GlobalExceptionHandler → 400 + 中文提示 |
| **鉴权异常** | BadCredentialsException → 401 |
| **权限异常** | AccessDeniedException → 403 |
| **参数校验** | MethodArgumentNotValidException → 422 + 字段级错误 |
| **未知异常** | Exception → 500 + 日志记录（不暴露给前端） |
| **日志级别** | Controller: INFO; Service: DEBUG; Security: INFO |
| **敏感信息** | 密码、Token 不出现在日志中 |

## 10 安全设计

| 层面 | 措施 |
|------|------|
| **传输** | HTTPS（生产环境）；本地开发 HTTP |
| **鉴权** | JWT (HS256)，24h 过期，前端存 localStorage |
| **密码** | BCrypt 加密存储 |
| **SQL 注入** | MyBatis-Plus 参数化查询（#{} 语法） |
| **CORS** | 配置允许跨域 origin pattern |
| **敏感字段** | password 字段查询后置 null，不序列化返回 |
| **管理员鉴权** | 方法级 `@PreAuthorize("hasRole('ADMIN')")` |
| **环境变量** | 数据库密码、JWT Secret 通过环境变量注入，不硬编码 |
